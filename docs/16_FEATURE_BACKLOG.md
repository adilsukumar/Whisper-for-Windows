# Feature Backlog and Expansion Ideas

This is a curated backlog, not a promise. Features move into the execution roadmap only after user evidence, architecture review, and a measurable success criterion.

## Near-term differentiators

### Smart cursor context

- Ask “what is this?” using UIA element-under-pointer plus a small visual crop.
- Cursor dwell preview showing the element name and available actions.
- Lasso/region selection for charts, diagrams, or dense application panels.

### Guided learning mode

- Step-by-step lessons with next/back/repeat/why.
- Detect whether the learner completed each step.
- Optional quiz and spaced-repetition summaries.
- Generate a private session cheat sheet without storing screenshots.

### Workflow capture

- User explicitly records a workflow demonstration.
- Convert clicks/UIA events into a semantic draft workflow.
- Let the user edit, name, test, and share a sanitized workflow.
- Detect application-version drift and flag broken steps.

### Privacy-first features

- One-click “local-only for the next request.”
- Preview exactly what context will be sent.
- Automatic notification/password-field redaction.
- Privacy receipt listing local/cloud processors per request.

## Post-MVP productivity

- Dictation with formatting, correction vocabulary, and insertion into the focused control.
- Clipboard-aware rewriting with explicit preview.
- Document/PDF context with local indexing.
- Cross-application search through user-approved sources.
- “Teach me what I just did” from a short explicit event buffer.
- Reusable personal commands with typed parameters.
- Meeting follow-up workflows only with clear recording/consent boundaries.

## App intelligence packs

Each pack includes supported versions, terminology, UIA quirks, workflows, fixtures, benchmarks, and fallback guidance.

Potential packs:

- Excel/PowerPoint.
- DaVinci Resolve/creative video.
- Blender/CAD.
- KiCad/electronics design.
- Visual Studio/VS Code/debugging.
- OBS/audio tools.
- Windows Settings and troubleshooting.

Prioritize packs using observed frequency, difficulty, willingness to pay, UI stability, UIA accessibility, and maintainability.

## Accessibility expansion

- Voice navigation mode with deterministic commands.
- Larger spotlight/captions and focus narration.
- Switch/dwell input support.
- Personalized pace and verbosity.
- Screen-reader cooperation rather than competing speech.
- Accessibility advisory review before marketing claims.

## Collaboration and teams

- Shareable sanitized workflow packs.
- Team-approved actions/providers/models.
- Central policy and audit export.
- Support-agent handoff with user-controlled context bundle.
- Organization-specific terminology and app packs.

## Extensibility

- Signed skills SDK with explicit capabilities.
- Declarative workflow format before arbitrary code plugins.
- Per-skill permissions, versioning, isolation, and revoke controls.
- Community gallery only after security review and moderation processes exist.

## Companion and delight

- Cosmetic companion packs and expressions.
- Optional sound themes.
- Multiple positioning styles: cursor, screen edge, tray-only.
- Context-sensitive but non-distracting reactions.
- Seasonal cosmetics without changing core affordances.

## Research bets

- Local small vision-language models specialized for Windows UI grounding.
- Screen-diff encoding instead of full repeated screenshots.
- Continual personalization using local preference learning.
- Robust canvas/game grounding where UIA is unavailable.
- Multi-agent planning only when a single planner cannot meet benchmark goals.
- Fine-tuning only after a legally sourced, consented, high-quality dataset exists.

## Explicitly deferred

- Unattended high-risk purchasing/account/security changes.
- UAC bypass or persistent full-admin operation.
- Invisible continuous screen recording.
- Open arbitrary-code marketplace.
- Training on user screenshots by default.
- Blockchain/token features unrelated to user value.
